# 03 - Embeddings & Vector Representations

## Source Summary
- **Topic:** Turning Text Meaning into Numbers
- **Key Takeaway:** Embedding models map text chunks and user queries into dense numerical vectors where semantic similarity corresponds to geometric closeness.

## Core Concepts
1. **Beyond Keyword Matching:** Traditional keyword search fails when a user asks about *"car maintenance"* while the document says *"automobile servicing"*.
2. **Dense Vectors:** An embedding model converts a sentence or paragraph into a list of numbers (for example, 384 or 768 dimensions) capturing meaning.
3. **Semantic Proximity:** Texts with similar meanings land near each other in vector space, enabling meaning-based lookup rather than exact word matching.
